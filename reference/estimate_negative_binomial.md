# Maximum likelihood estimation for the negative binomial distribution.

Given data, computes the maximum likelihood estimators for the negative
binomial distribution with parameters: size and mu.

## Usage

``` r
estimate_negative_binomial(data, verbose = FALSE)
```

## Arguments

- data:

  The data to estimate parameters from.

- verbose:

  Whether or not to show all logging.

## Value

Maximum likelihood estimators size and mu for the negative binomial
distribution
